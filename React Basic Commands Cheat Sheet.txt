React Basic Commands Cheat Sheet

1. Check Node.js Version


node --version
or
node -v



2. Check npm Version

npm --version
or
npm -v






3. Create a React App


Using Create React App (CRA)

npx create-react-app my-app
or
npx create-react-app student-app





4. Go Inside the Project Folder



cd my-app
or
cd student-app


5. Start the React App

npm start

ex : http://localhost:3000



6. Check React Version

npm list react

ex: react@19.1.0

7. Check React + React DOM Version

npm list react react-dom



8. Stop the React Server
CTRL + C
Y


9. Open the Project in VS Code

code .


or 
If code does not work:

Open VS Code manually
Click:
File → Open Folder



10. Install a Package

Example: install Axios


npm install axios




11. Run Build for Production
npm run build





12. Create React App Using Modern Method (Recommended)

Today many developers use Vite instead of CRA.

Create React App with Vite



npm create vite@latest

or 

cd project-name
npm install
npm run dev





13. Most Important Daily Commands
